## 9. Fresha UI/UX Observations (for Dastaan Platform)

### What Fresha Does Well

**Layout & Navigation:**
- Collapsible icon-based left sidebar — minimal footprint, icons with tooltips
- Two-panel layout in settings: sub-nav on left, content on right
- Category filter panel sits between navigation and content — fast filtering without page reload
- Breadcrumb navigation in deep settings pages

**Visual Design (Light theme):**
- Almost-white (#F8F8F8) content background with soft card shadows
- Purple/violet (`#6C47FF` approx) as primary accent for active states and CTAs
- Dark navy sidebar (`#111827` approx) contrasts cleanly against light content
- Service cards have a left-border accent in the category color (a nice hierarchy cue)
- Count badges (e.g., "9" next to Hair Services) in small rounded grey pills

**Interaction Patterns:**
- Three-dot "More" action menus on each service card — non-destructive, keeps UI clean
- Category filter updates URL (`?services-category=ID`) — deep-linkable states
- Pagination with explicit "Viewing X–Y of Z" counter
- "Actions" dropdown on location/team cards with contextual options
- Rating display inline with star count — builds trust
- Invitation status shown on team member cards (e.g., "Invitation expired")

**Data Density:**
- Products table is dense but scannable: name, category, supplier, quantity, price in columns
- Team list shows role + rating in a single card
- Service cards show duration prominently as the first sub-line after the name

### What Could Be Better (Opportunities for Dastaan)

| Pain Point in Fresha | Dastaan Opportunity |
|---------------------|---------------------|
| Virtual/infinite scroll makes scraping hard — services disappear from DOM | Load all items in DOM; use CSS visibility toggle instead of unmounting |
| No global search across services + clients + staff at once | Unified search bar (⌘K) across all entity types |
| Service cards show minimal info — have to click "More" to see details | Expandable service cards with inline details on hover/click |
| Products show negative stock without alerts or urgency styling | Red stock badges, low-stock alerts, reorder suggestions |
| Calendar is the default landing page but dashboard shows more useful KPIs | Make the analytics dashboard the home screen with calendar as secondary |
| Category counts include archived items in total count (confusing) | Separate active vs. archived counts clearly |
| Team cards don't show which services each barber offers | Staff profiles with service specialisations and available slots |
| No dark mode | Dastaan's dark gold/ivory theme is a differentiator — lean into it |
| Limited brand personality | Dastaan can show brand photos, ambiance, loyalty story in the UI |

### Dastaan Design Recommendations

Given the **dark gold/ivory** theme:
- Primary background: `#1A1612` (near-black warm brown)
- Card surfaces: `#252018` (slightly lighter)
- Gold accent: `#C9A84C` or `#D4A843` (for CTAs, active states, ratings)
- Ivory/cream text: `#F5EDD8`
- Dividers/borders: `#3A3020`
- Service category left-borders: use gold tints (`#9A7A32`, `#C9A84C`, `#E8C97A`)
- Use serif or elegant sans font for service names (feels premium vs. Fresha's utilitarian sans)
- Staff cards with profile photos, not just initials — this is a salon, faces matter
